# Shared sources

- `literature_matrix.csv`: one row per candidate reference; fill review and verification status.
- `initial_reading_notes.md`: starting notes from the existing draft; authors must verify the original publications themselves.
- `../../paper/references.bib`: canonical BibTeX source. Add new references here only after checking metadata.

For benchmark results, also fill `../../data/benchmark_evidence_template.csv` or make a clearly named new CSV for verified evidence.
