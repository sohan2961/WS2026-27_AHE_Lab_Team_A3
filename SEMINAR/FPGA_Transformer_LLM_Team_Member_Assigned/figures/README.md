# Figures

Place **original** SVG/PNG/PDF figure files and, when possible, the editable source (SVG, Python or TikZ) here. Name them `fig1_attention_pipeline.svg`, `fig2_memory_hierarchy.svg`, etc.

For each figure, include a caption in `figure_index.md`, the research point supported, data source (if a graph), and whether it is original, adapted with attribution, or reused with permission.

The initial `paper/main.tex` has TikZ diagrams embedded in the LaTeX source. These can be extracted into separate `.tex` files if the team prefers.
